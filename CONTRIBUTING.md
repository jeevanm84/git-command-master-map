# Contributing

Contributions should improve understanding, safety, or reproducible Git behavior.

1. Fork the repository and create a focused branch.
2. Keep examples original and free of private repository history.
3. Run destructive examples only in sandboxes created by `scripts/new-sandbox.sh`.
4. Include objective, observation, verification, recovery, explanation, and cleanup in new labs.
5. Run `./scripts/check.sh` and open a pull request using the template.

Do not include credentials, internal URLs, customer or employer information, real incident data, or proprietary source code.
